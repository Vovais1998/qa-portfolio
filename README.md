# Портфолио QA Engineer — Владимир Иванов

## Обо мне

- Составление чек-листов и тест-кейсов
- Функциональное, регрессионное и smoke-тестирование
- Тестирование REST API в Postman
- Работа со спецификациями Swagger/OpenAPI
- Проверка HTTP-статусов, JSON-ответов и обработки ошибок
- Выполнение SQL-запросов и проверка данных в PostgreSQL
- Анализ HTTP-запросов и ответов
- Оформление и сопровождение баг-репортов
- Базовая работа с Git: коммиты, ветки, merge, rebase, cherry-pick, fetch, pull и push
