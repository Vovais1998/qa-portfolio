## Подробное описание

<details>
<summary><strong>REG-001 — Успешная регистрация при заполнении всех полей</strong></summary>

**Приоритет:** Высокий

**Теги:** `frontend`, `positive`, `registration`, `smoke`

**Тестовые данные:**

```text
Тестовые данные:
Логин: qausertest
Пароль: TestPass!2026
Повторите пароль: TestPass!2026
Пол: Мужской
Почта: qausertest@yandex.ru
День: 15
Месяц: Май
Год: 2000
```

| № | Шаг | Ожидаемый результат |
|---:|---|---|
| 1 | Ввести qausertest в поле «Логин». | В поле отображается qausertest. |
| 2 | Ввести TestPass!2026 в поле «Пароль». | Поле заполнено введённым паролем. |
| 3 | Ввести TestPass!2026 в поле «Повторите пароль». | Поле заполнено значением, совпадающим с паролем. |
| 4 | Открыть список «Выберите пол». | Отображаются варианты «Мужской» и «Женский». |
| 5 | Выбрать «Мужской». | В поле отображается «Мужской». |
| 6 | Ввести qausertest@yandex.ru в поле «Почта». | В поле отображается qausertest@yandex.ru. |
| 7 | Ввести 15 в поле «День». | В поле отображается 15. |
| 8 | Открыть список «Месяц» и выбрать «Май». | В поле отображается «Май». |
| 9 | Ввести 2000 в поле «Год» и перевести фокус за пределы поля. | В поле отображается 2000. Все поля заполнены. Кнопка «Регистрация» имеет зелёный цвет #2DC75C. |
| 10 | Нажать кнопку «Регистрация». | Регистрация завершается успешно. В системе создан пользователь с логином qausertest, почтой qausertest@yandex.ru, полом «Мужской» и датой рождения 15.05.2000. |

**Постусловия:**

- Удалить созданного тестового пользователя доступным на стенде способом, чтобы освободить данные для повторного выполнения.
