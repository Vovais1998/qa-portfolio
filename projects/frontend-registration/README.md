# Тестирование формы регистрации

## О проекте

Учебный проект по проектированию тестов для веб-формы регистрации. Тест-кейсы первоначально оформлялись в Test IT. Для портфолио они перенесены в Markdown без закрытых ссылок на учебное рабочее пространство.

## Что проверяется

- регистрация со всеми полями и только с обязательными полями;
- обязательность полей;
- совпадение пароля и подтверждения;
- формат адреса электронной почты;
- граничные значения возраста, длины логина и пароля;
- ограничения полей дня и года;
- работа выпадающих списков;
- оформление и адаптивность формы.

## Применённые техники

- классы эквивалентности;
- анализ граничных значений;
- позитивное и негативное тестирование;
- тестирование обязательных полей;
- UI- и адаптивное тестирование.

## Результат

Разработано 25 тест-кейсов с предусловиями, тестовыми данными, шагами, ожидаемыми результатами, приоритетами и тегами.
