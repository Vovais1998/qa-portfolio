# BR-API-001 — Создание товара с пустым телом или неверными типами возвращает 201

| Поле | Значение |
|---|---|
| Компонент | Fake Store API, `POST /products` |
| Тип | Валидация входных данных |
| Влияние | Среднее |
| Приоритет | Нормальный |
| Воспроизводимость | Всегда |
| Дата проверки | 18.09.2026 |

## Предусловия

- API доступно по адресу `https://fakestoreapi.com`.
- Заголовок запроса: `Content-Type: application/json`.

## Шаги воспроизведения

1. Отправить запрос `POST https://fakestoreapi.com/products`.
2. Передать пустой JSON-объект `{}` в теле запроса.
3. Проверить HTTP-статус и тело ответа.

Пример cURL:

```bash
curl --request POST 'https://fakestoreapi.com/products' \
  --header 'Content-Type: application/json' \
  --data '{}'
```

## Ожидаемый результат

Сервер отклоняет запрос со статусом `400 Bad Request` и сообщает об отсутствии обязательных полей товара.

## Фактический результат

Сервер возвращает `201 Created` и создаёт ответ с идентификатором:

```json
{"id": 21}
```

Запрос со значениями неверных типов также возвращает `201 Created`, а некорректные значения попадают в ответ без валидации.
