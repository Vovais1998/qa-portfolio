# BR-API-002 — Создание корзины с пустым телом или неверными типами возвращает 201

| Поле | Значение |
|---|---|
| Компонент | Fake Store API, `POST /carts` |
| Тип | Валидация входных данных |
| Влияние | Среднее |
| Приоритет | Нормальный |
| Воспроизводимость | Всегда |
| Дата проверки | 18.09.2026 |

## Предусловия

- API доступно по адресу `https://fakestoreapi.com`.
- Заголовок запроса: `Content-Type: application/json`.

## Шаги воспроизведения

1. Отправить запрос `POST https://fakestoreapi.com/carts`.
2. Передать пустой JSON-объект `{}` в теле запроса.
3. Проверить HTTP-статус и тело ответа.

Пример cURL:

```bash
curl --request POST 'https://fakestoreapi.com/carts' \
  --header 'Content-Type: application/json' \
  --data '{}'
```

## Ожидаемый результат

Сервер отклоняет запрос со статусом `400 Bad Request` и сообщает об отсутствии обязательных полей корзины.

## Фактический результат

Сервер возвращает `201 Created` и создаёт ответ с идентификатором:

```json
{"id": 11}
```

Запрос со строкой вместо `userId`, числом вместо даты и строкой вместо массива `products` также возвращает `201 Created`. Некорректные значения попадают в ответ без валидации.
