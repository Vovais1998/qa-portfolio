# Результаты негативных проверок

- Дата проверки: 18.09.2026
- Окружение: `https://fakestoreapi.com`
- Формат запросов: `Content-Type: application/json`

| Проверка | Ожидаемый статус | Фактический статус | Фактический ответ | Результат |
|---|---:|---:|---|---|
| `POST /products` с пустым телом `{}` | 400 | 201 | `{"id":21}` | Не пройдена |
| `POST /products` со значениями неверных типов | 400 | 201 | API вернул `id` и переданные некорректные значения | Не пройдена |
| `POST /carts` с пустым телом `{}` | 400 | 201 | `{"id":11}` | Не пройдена |
| `POST /carts` со значениями неверных типов | 400 | 201 | API вернул `id` и переданные некорректные значения | Не пройдена |

Ожидаемое поведение задано тестовой моделью проекта: обязательные поля должны присутствовать, а значения должны соответствовать заявленным типам. По результатам оформлены два баг-репорта.
